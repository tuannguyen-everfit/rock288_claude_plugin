# Learn Faster (FASTER Method)

Accelerated learning framework for developers.

## FASTER Method

| Step | Action | Description |
|------|--------|-------------|
| **F** | Forget | Forget what you think you know — approach with beginner's mind |
| **A** | Active | Active learning — code along, don't just read |
| **S** | State | Manage your state — take breaks, stay curious |
| **T** | Teach | Teach what you learn — explain it back |
| **E** | Enter | Enter it into practice — build something real |
| **R** | Review | Spaced review — revisit at increasing intervals |

## Workflow

### Step 1: Topic Assessment

```
## Learning Plan: [Topic]

**Current Level:** Beginner | Intermediate | Advanced
**Goal:** [What you want to be able to do]
**Time Budget:** [Hours/days available]
**Prerequisites:** [What you already know]
```

### Step 2: Create Learning Path

Build a structured curriculum:

```
Level 1: Fundamentals (Day 1)
├── Concept: [Core concept 1]
│   ├── Explanation
│   ├── Code example
│   └── Exercise
├── Concept: [Core concept 2]
│   ├── Explanation
│   ├── Code example
│   └── Exercise
└── Quiz: Fundamentals check

Level 2: Practical (Day 2-3)
├── Build: [Mini project 1]
├── Build: [Mini project 2]
└── Quiz: Practical check

Level 3: Advanced (Day 4-5)
├── Concept: [Advanced topic 1]
├── Concept: [Advanced topic 2]
├── Build: [Real-world project]
└── Quiz: Advanced check
```

### Step 3: Active Learning Exercises

For each concept, provide:

1. **Explain Like I'm 5** — Simple analogy
2. **Show Me The Code** — Minimal working example
3. **Try It Yourself** — Exercise with hints
4. **Common Gotchas** — Mistakes everyone makes
5. **Real-World Usage** — How it's used in production

### Step 4: Teach Back

After each level, summarize what you learned:
- Explain the concept in your own words
- Draw connections to things you already know
- Identify what's still unclear

### Step 5: Spaced Review Schedule

```
Day 1: Learn + immediate review
Day 2: Review yesterday's material (10 min)
Day 4: Review all material (15 min)
Day 7: Review + quiz (20 min)
Day 14: Review + build something (30 min)
Day 30: Final review + teach someone
```

| Getting started tutorial | First hands-on experience |
